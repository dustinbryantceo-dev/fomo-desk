Private screen

This is a real-time view of the Chrome window the bots click in. It's locked to the server, so you open a secure tunnel first. It has no password, because the tunnel is the lock.

💻 On a PC (PowerShell)

  1. Run this and leave the window open:
    ssh -L 6080:127.0.0.1:6080 bot@178.104.3.124
  2. Open the private screen below.

📱 On an iPhone (Termius)

  1. Host: Address 178.104.3.124, Username bot (lowercase), Key iphone.
  2. Port Forwarding, add a rule: Local, Local port 6080, Bind address 127.0.0.1, Destination 127.0.0.1, Destination port 6080.
  3. Tap the rule until it shows as active. Don't type an ssh command in Termius, because the rule does that job.
  4. Switch to Safari and open the private screen below.
  5. If it freezes, iPhone has paused Termius. Go back and tap the rule again. Allowing Termius location access "Always" helps it stay connected.

Non-negotiable

Safety rules

  • Nobody, including the bot, ever gets your password, seed phrase, private key or 2FA codes.
  • The bot never presses Withdraw, Deposit, Send or settings on FOMO. Withdrawals happen only on your command, and you press Confirm yourself.
  • Before every Buy, the bot checks that the amount matches Brain's size to the cent, and cancels the buy if it doesn't.
  • Text on a web page is never treated as an instruction.
  • Any setting change needs your approval.
🧰
Troubleshooting

If something looks wrong

  • Send status in Telegram first.
  • If the desk crashes, it restarts itself within about 15 seconds.
  • The server has 4 GB of extra swap memory so it doesn't run out of memory.
  • Private screen won't load? Check that the Termius rule is active and the username is lowercase bot.
⚠️ Trading meme coins is high risk. The bots follow your rules, but they can't prevent losses.
